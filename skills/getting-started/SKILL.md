# Getting started: the intake

Serves the install (START-HERE Steps 0–3).

## Inputs
- `owner.md` (project file; the master copy is `AI Team/context/owner.md`), filled from the private client file at install.
- `CLIENT-CONTEXT.template.md`: the headings owner.md must have.
- `OPEN_QUESTIONS.md`: the questions waiting on Chris, with the milestone that needs each.

## Steps
1. Read `owner.md` back in one short message: "Here's what I know about the business. Is anything wrong or missing?" Fix only what Adrielle or Chris corrects.
2. Ask every line still marked `ASK`, then the OPEN_QUESTIONS rows the current milestone needs:
   - one question per message;
   - short enough to answer on a phone;
   - offer choices when there are only a few.
3. Questions only Chris can answer go into one list, for Adrielle to raise at the morning catch-up. Don't chase Chris directly.
4. Write each answer in place of its `ASK`, with today's date. A required field nobody knows yet stays `REQUIRED`; never guess it.
5. Give Adrielle the whole corrected owner.md in one block. She saves it over `AI Team/context/owner.md` and replaces the project file in every desk.

## Output
The corrected owner.md, and a list of what's still `REQUIRED`, with the milestone that needs each.

## Done when
No `ASK` is left that the current milestone needs, and Adrielle has said "right" to the readback.

## Never
- Ask for a password, code or key.
- Invent a fact to fill a gap.
- Ask two questions in one message.
