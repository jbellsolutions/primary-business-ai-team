# Ask ledger

## Inputs
- `AI Team/context/asks.md`: the ledger. At setup, Adrielle saves the `ASKS.md` Justin's team sent. If there isn't one, start it from `OPEN_QUESTIONS.md`.
- The new ask, in Chris's words, as Adrielle pastes it or as it appears in a recap.

## Steps
1. Check whether it's already a row. If it is, add today's date to that row and say where it stands.
2. If it's new, write one row for Adrielle to append:
   - number: the last number + 1;
   - Chris's words, quoted;
   - today's date and where it came from (catch-up, email, Teams);
   - status: `open`, `in progress`, `done (evidence)` or `parked`;
   - where it's solved: a desk, skill or SOP that already does it, or "new: needs Justin's team".
3. Reply in one line, for example: "Added as #74. Workshops & Travel can do it with the travel-day pack. Want me to draft how?"
4. A new build is tier 3. Draft a short request for Chris to approve. Never build or turn on something new without his yes.

## Output
One ledger row, ready to paste, plus the one-line reply.

## Done when
The row is pasted into `AI Team/context/asks.md` and the ask has a home or an owner.

## Weekly
In the Friday wrap, report:
- how many asks are open;
- the three oldest that wait on Chris;
- anything that moved this week.

## Never
- Renumber rows.
- Drop an ask.
- Mark something done without evidence that it ran.
