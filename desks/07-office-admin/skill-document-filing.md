# Document filing

Serves #64. Follows SOP 28. Filing the email itself is a separate job, done by the Team Lead (inbox triage). The desk only suggests where and what to call it.

## Inputs
- The document: its name, its type and what it says, pasted or described. Only the facts needed to file it.
- The OneDrive folder tree (read it, or Adrielle pastes the top levels): project, workshop, finance, travel and admin.
- `owner.md`: the project names, and the line `Restricted folders`. If Chris hasn't named them, that is UNKNOWN.
- The Todoist task the document belongs to, if there is one.
- A few existing file names Adrielle pastes from the folder, so a new name matches the way Chris's files already look.

## Steps
1. Name the document type (invoice, receipt, flyer, report, contract, booking, other) and the project, workshop or trip it belongs to. If you can't tell, ask one question.
2. Choose the category from the folders that already exist. Search the tree for the folder; never propose a new top-level folder. If none fits, say "No folder fits" with the two nearest, and ask Chris through Adrielle.
3. Name the file `<YYYY-MM-DD> <what> <project>` (check with Chris). The date is the document's own date, such as the invoice date. A later version adds `v2`, `v3`. Check the folder for the same name: never overwrite.
4. Look for an existing copy (same invoice number, same flyer). Keep one copy and share links, not copies.
5. Decide whether it is confidential: participant lists, contracts, bank details. Those go only in the restricted folders. If the restricted folders aren't known, mark "UNKNOWN: restricted folder" and hold the file there.
6. Keep sets together. An invoice and its remittance go in the same folder (SOP 21). A receipt goes in the trip or project folder it belongs to (SOP 22). A flyer goes in its workshop folder. A report goes in the project folder, with the version in its name.
7. For a batch, give one line per file, in an order Adrielle can work down. Group the files by destination folder.
8. Add what Adrielle does last: put the link on the Todoist task, and clear the loose copy from Downloads or the desktop.

## Output
A table, one row per document: current name, save to (the full folder path), new file name, confidential yes or no, the Todoist task to link, and notes (duplicate found, version, question).
After the table, list any "No folder fits" or "UNKNOWN: restricted folder" items as questions, one at a time, for Adrielle to put to Chris.

Example row: invoice from `<payee>` | save to the finance folder, `<project>` subfolder | `<YYYY-MM-DD> invoice <payee> <project>` | confidential: no | link on the payment's Todoist task | no earlier copy found.

## Done when
Every document in the batch has a folder path that exists, a file name by the rule, a confidential mark, and no new top-level folder or overwritten file.

## Never
- Move, rename, delete, upload or share any file.
- Suggest sharing outside the business.
- Copy a document's contents into a note or a chat beyond what's needed to file it.
- Put a confidential file anywhere but a restricted folder.
