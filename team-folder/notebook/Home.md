# AI Team notebook

The team's memory. Plain markdown, so it opens in OneDrive, Word, or Obsidian (open the `AI Team/notebook` folder as a vault to see the links as a graph).

- [[Decisions]]: every decision Chris makes about how the team works, with the date
- [[Parking-lot]]: ideas Chris parked, with the date to raise each one
- [[Handover list]]: everything Chris could hand over
- [[Glossary]]: the industry's words, in plain English
- [[Automation backlog]]: what's worth automating, ranked
- [[SOP gaps]]: tasks still without an SOP
- `Daily/`: one note per working day: the plan, what got done, what's waiting on Chris, and the routines' status lines
- `../sops/`: the SOP library
- `../context/`: owner facts, switches, approvals, registry, ask ledger
